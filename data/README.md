# Dataset

Place the standard banking churn dataset here with this exact filename:

`Churn_Modelling.csv`

Expected columns:

CustomerId, Surname, CreditScore, Geography, Gender, Age, Tenure,
Balance, NumOfProducts, HasCrCard, IsActiveMember, EstimatedSalary, Exited

The project intentionally does not redistribute the dataset. Obtain it from a legitimate dataset source such as Kaggle and keep the CSV locally.

The application validates the schema before running.
